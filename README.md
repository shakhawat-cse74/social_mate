# SocialMate

**SocialMate** is a unified omnichannel social media CRM, inbox, and AI agent platform.

## Features
- **Omnichannel Live Inbox**: Connect Facebook Messenger, Instagram, WhatsApp, Telegram, and Web Chat into a single inbox.
- **AI Auto-Reply Agents**: Intelligent AI responses powered by Google Gemini, OpenAI, Claude, or custom models.
- **CRM & Sales Pipeline**: Multi-stage deals, leads, customer management, and activity logs.
- **Multi-Tenant Architecture**: Workspace separation for teams and clients with granular permissions.
- **Web Widget**: Embeddable live chat widget with audio/video calls and quick replies.
